# SupplyPrescript

## Closed-Loop Prescriptive Analytics for Supply Chain Decision Support

SupplyPrescript is a supply chain decision-support system that predicts
microchip shipment delays and recommends optimal actions based on cost,
delivery time, quantity, and capacity constraints.

## Project Flow

Shipment Data
→ Delay Prediction
→ Prescriptive Optimization
→ Recommended Actions
→ Manager Decision
→ Database Write-Back
→ Outcome Evaluation

## Domain

Supply Chain Operations & Prescriptive Analytics

## Dataset

Synthetic historical microchip shipment data

## Prediction

The system predicts:
1. Whether a microchip shipment is likely to be delayed.
2. The expected duration of the delay.

## Prescriptive Solutions

The system evaluates alternatives such as:
1. Air Freight
2. Secondary Supplier
3. Accepting the Delay

## Optimization Constraints

- Budget
- Maximum acceptable delivery time
- Supplier capacity
- Required quantity
